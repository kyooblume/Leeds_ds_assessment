# 🇬🇧 UK Tourist Analysis Dashboard

> Leeds Trinity University data science assessment (2025)
> Data source: Japan Tourism Agency, *Consumption Trend Survey for Foreigners Visiting Japan* (訪日外国人消費動向調査)

**English:** Streamlit dashboard giving a 360° view of UK tourists in Japan, from demographics to detailed spending habits, to identify strategic opportunities.

**日本語:** 日本を訪れるイギリス人観光客について、属性から消費行動までを可視化した Streamlit ダッシュボード（Leeds Trinity Universityの課題）。

## Files
| File | Description |
|---|---|
| `app.py` | Streamlit app |
| `summary_data.csv`, `expenditure_data.csv` | Cleaned input data |
| `formatted data.xlsx` | Formatted source data |

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

**Tech:** Python, Streamlit, pandas, Altair
